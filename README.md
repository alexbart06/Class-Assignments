# Class-Assignments
# Project 1: Interactive TV
For this project, I made a TV that you can turn on and off by clicking a button. You can also change between two channels and press Q while hovering over the other button to display a message.

# Project 2: Halloween Pumpkin
For this project, I made a Halloween pumpkin with animated green rain falling in the background. I used an array and a for loop to make the rain move. Clicking also creates a green circle that slowly fades away.

# Project 3: Ball Physics
For this project, I used the p5play library to create a physics simulation. You can click to drop red balls that fall using gravity and bounce off blue triangles. The program counts collisions with the triangles, and pressing R resets the balls and counter.
